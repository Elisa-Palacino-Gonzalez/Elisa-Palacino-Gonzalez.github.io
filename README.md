# Elisa Palacino González — personal research website

Static GitHub Pages website for:
`elisa-palacino-gonzalez.github.io`

The public site intentionally excludes confidential research material.

Deployment:
1. Create/use the repository `elisa-palacino-gonzalez.github.io`.
2. Upload the contents of this folder to the repository root.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.

The website presents Elisa as a Postdoctoral Researcher at CNRS / University of Nantes, with a detailed career trajectory, PhD and IMPRS-APS background, competitively awarded fellowships, teaching/course coordination, international collaboration network, and publication links.
